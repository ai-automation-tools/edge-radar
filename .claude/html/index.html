Halting orders

First, stop everything: set DRY_RUN=true in .env. The CLI re-reads .env per run, so the next fire of every execute task is already dry.

To stop one task instead, disable it:

Get-ScheduledTask -TaskName '<task>' | Disable-ScheduledTask

Positions already open are held, not flattened: exiting a 5–20c-wide book pays exactly the illiquidity penalty Gate 3.6 exists to avoid.
